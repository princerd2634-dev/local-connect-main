# Local Connect

A full-stack local service discovery and request management platform
that connects users with local service providers.

## Features

- User registration and authentication
- Service browsing and search
- Service details
- Service request submission
- User dashboard
- Provider management
- Admin dashboard
- Role-based access control
- Supabase database integration
- Responsive UI

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase
- React Router
- React Query
- Vitest
- Playwright
